## 1) Per-editor checker singleton lifecycle

```js
// nhg = Ei(() => ({ key: undefined, checker: undefined }))
function DCc(e, t, r) {
  let n = nhg.of(e), o = `${t}:${r ?? ""}`;
  if (n.checker && n.key === o) return n.checker;
  return n.checker?.dispose(), n.key = o, n.checker = new ihg(() => AuE(t, r)), n.checker;
}
function ohg(e) {
  let t = nhg.of(e);
  t.checker?.dispose(), t.key = void 0, t.checker = void 0;
}
```

- Host key is the PromptInput/`Ar.host` object (WeakMap-style `Ei.of`).
- Remint when checker/language key changes: dispose old `ihg`, construct new.
- Disable: `ohg(host)` clears singleton.

### `ihg` status machine (public-facing + internal)

User-facing / requested states:
- `resolving` — `#w()` looking up checker binary via `#h()` (`AuE`)
- `starting` — process spawned, waiting for banner
- `ready` — banner parsed, stdin protocol live
- `unavailable` — lookup miss / permanent failure after restart budget

Also present (internal, not in the 4-name list):
- `idle` — initial / after `#D()` teardown before next spawn; spawn failure temporarily returns here then `#E`

Transitions (abbrev):
1. `idle` → `resolving` (`#w`)
2. lookup null → `unavailable` (+ clear queue); telemetry `checker_lookup_failed` / `checker_not_found`
3. spawn ok → `starting` → banner ok → `ready` (telemetry `_e("input_spellcheck",{backend})`)
4. any crash/protocol/timeout path → `#E` → restart-once or `#M` → `unavailable`

## 2) Restart-once on crash

Constants (module `shg`):
- `PuE = 1` — max restart count (`#n < PuE`)
- `IuE = 1000` — delay before restart attempt
- `thg = 3` — slow-response strikes before `checker_too_slow` → unavailable
- `RuE = 3000` banner timeout; `xuE = 15000` response timeout

```js
#E(e, t) {
  if (this.#r || this.#t.status === "unavailable") return;
  if (this.#D(), this.#i = 0, this.#n < PuE) {
    this.#n++;
    T(`[spellcheck] ${e}; restarting once`, { level: "warn" });
    this.#s = true;
    this.#m = setTimeout(() => { this.#s = false; this.#b(); }, IuE);
    this.#m.unref?.();
    return;
  }
  this.#M(e, t);
}
#M(e, t) {
  T(`[spellcheck] ${e}; spell checking is off for this session`, { level: "warn" });
  pe("input_spellcheck", t);
  this.#D();
  this.#t = { status: "unavailable" };
  this.#c.clear();
}
```

`#D()` always resets status to `idle`, re-queues in-flight words (`#d` → `#c`), kills process if `starting|ready`.

## 3) Verdicts + `fhg` non-overlapping merge

`ihg.verdicts` is a fresh object `{ isMisspelled(word) }` rebound on each `#C` batch; `changed` EventTarget/`ps()` notifies React.

```js
function fhg(e, t) {
  if (t.length === 0) return e;
  let r = [...e];
  for (let n of t)
    if (!e.some((o) => n.start < o.end && n.end > o.start)) r.push(n);
  return r;
}
```

Semantics: keep all base PromptInput ranges; append each spell range only if it does **not** overlap any *existing base* range (`e`, not the accumulating `r`). Spell ranges never displace higher-priority UI marks.

Call site (PromptInput body ~@294865312):


Renderer chain (mangled; **not** named `HighlightedInput`):
1. `Ll(props)` passes `highlights: e.highlights` into `S4i`
2. `S4i` filters cursor-covered non-`dimColor` ranges, maps via `MNm` to rendered offsets
3. `GSl({text, highlights})` → `NSl` priority-sort + non-nesting segmenter → line tokens
4. Paint:
```js
_.jsx(_, {
  color: Hrt.highlight?.color,
  dimColor: Hrt.highlight?.dimColor,
  inverse: Hrt.highlight?.inverse,
  underline: Hrt.highlight?.underline,
  children: _.jsx(nd, { children: Hrt.text }),
})
```
Misspells therefore render as **theme/ansi `color` + `underline: true`** at priority `2`.

`NSl` keeps higher-priority overlapping ranges (sort by start asc, priority desc) and drops nested/overlapping losers before segmentation — complementary to `fhg` which already refused overlapping spell inserts against base marks.

## 6) Dispose on disable

From `mhg` effect:
- `enabled !== true` → `ohg(host)` + React state `undefined`
- `ohg` → `checker.dispose()`:
  - sets `#r` disposed flag
  - `#D()` kills process / clears timers
  - clears pending word set + `changed` listeners

Remint on checker/language change also disposes previous instance inside `DCc`.

## Gaps / notes for local port
1. No SEA symbol literally named `HighlightedInput` — port should wire through existing PromptInput → TextInput (`Ll`/`S4i`) `highlights` prop + `GSl`/`NSl` underline path (or local equivalent).
2. `ihg` also uses internal `idle` status; product docs often only list resolving|starting|ready|unavailable.
3. `fhg` overlap test is against the *pre-merge base array only*; two spell ranges that overlap each other would both be kept if neither overlaps base (lhg normally prevents that).
4. PromptInput component itself is an anonymous large function; host object `Ar.host` is the singleton key identity.
5. Cursor-under-range filtering in `S4i` (`cursorOffset` inside range hides non-dim highlights) applies to spell underlines while typing over them unless `dimColor`.
6. Full aspell/hunspell/ispell protocol + `AuE` PATH lookup is covered in gold-spellcheck-runtime / protocol snippets — not duplicated here beyond lifecycle hooks.
