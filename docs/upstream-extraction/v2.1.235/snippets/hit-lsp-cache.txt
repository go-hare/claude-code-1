## Mechanism (SEA-proven)
LSPTool.isEnabled() latches via hasEverConnected (not live isConnected).
Once any non-error LSP server has been seen connected, disconnect/reconnect must NOT
flip tool schema presence → avoids toolSchemasChanged / whole prompt-cache break.

SEA aliases:
  GUr = hasEverConnected
  ZMA = isConnected
  Jnr = getStatus
  zii = reinitialize
  lpT = shouldDeferLspTool-like helper (if GUr() return false)
