## 2. `claude ssh` is one of four mutually exclusive remote backends

@221654975 (the --cloud / --environment validator, `${n}` = the flag under test):

  if (e.hasConnect || e.hasSSH || e.hasAssistant || e.hasTeleport) {
    let t = e.hasConnect ? "a cc:// connect URL"
          : e.hasSSH ? "`claude ssh`"
          : e.hasAssistant ? "`claude assistant`"
          : "--teleport";
    return `Error: ${n} cannot be combined with ${t} \u2014 both select a remote backend; pick one.`
  }

  Also in the same validator: `${n}` cannot be combined with --continue, and
  cannot be combined with --resume / --from-pr. Note this constrains `${n}`
  (a backend selector), NOT ssh's own flag set -- it says nothing about whether
  `claude ssh` may take --continue/--resume.
