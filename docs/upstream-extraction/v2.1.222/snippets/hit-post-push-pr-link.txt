## Product flow
1. Successful `git push` (not dry-run, no concurrent gh pr action):
   - optional explicit colon-refspec branch → `gh pr view <branch>`
   - always current branch → `gh pr view` (no selector)
   - if view fails → register pendingBranchLinks{cwd,branch,attempts:0}
2. Later successful git/gh/glab/curl → Pc_ retries ndn up to kc_=5
3. `gh pr create` / `glab mr create` / curl REST create with PR URL in stdout → K$s link + clear pending for cwd
4. REST create without immediate URL still links via step 2 once PR exists
