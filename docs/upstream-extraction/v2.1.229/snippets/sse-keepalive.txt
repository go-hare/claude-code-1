## Product surface

densable **gateway host** emits SSE `event: ping` during silent gaps when
proxying Vertex/Bedrock (their SDKs drop upstream pings / Bedrock sends none).

SEA:
- `tBw = \`event: ping\ndata: {"type": "ping"}\n\n\``
- `eBw = 15000` (related interval in gateway region)
- protocol docs: "emit your own `event: ping` during silent gaps so long
  thinking pauses don't trip client or proxy idle timeouts"

## Not CLI invent

Local **client** residual already landed densable 2.1.222 **Tfb**:
`src/utils/streamKeepAlive.ts` — synthetic `{type:"ping"}` when body bytes
advance but no SSE event (consumer idle reset). That is **client-side**, not
gateway emit of `event: ping` on the wire.

No go-hare package is the densable cloud gateway that serves Vertex/Bedrock
translation. Do not invent a gateway ping emitter in the CLI.
