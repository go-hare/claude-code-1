## Contract

Ink field: `frameSink = null` (writable from React host `xxc`).

Signature installed by xxc:

```ts
frameSink: (frame, stylePool) => "tick" | true | false
```

| return from sink | Ink `onRender` behavior |
|------------------|-------------------------|
| falsy (`false`, or no sink) | fall through to normal cell-diff paint (`writeDiff` / dj8 path) |
| truthy (`true` **or** `"tick"`) | swap `frontFrame`/`backFrame` to the just-rendered frame; `prevFrameContaminated=false`; `maybeResetPools`; call `onFrame`; **return early** (skip cell-diff write) |
| `"tick"` (subset of truthy) | additionally `drainTimer = setTimeout(() => this.onRender(), hX>>2)` so pump keeps draining |

Alt-screen suspend is **inside the sink (xxc)**, not Ink:
- when `h.isAltScreenActive`: `Axc.suspend()` once, return `false` → Ink paints normally (alt-screen cell blit).
- Axc is the **main-screen** sticky compositor only.

## `onRender` invoke site @ 308652923 (method head @ ~308652088)

After `this.renderer({frontFrame, backFrame, ... overlayActive})` returns frame `c`:

```js
if(this.frameSink){
  let W=this.frameSink(c,this.stylePool);
  if(W){
    if(this.backFrame=this.frontFrame,this.frontFrame=c,this.prevFrameContaminated=!1,this.maybeResetPools(e),W==="tick")
      this.drainTimer=setTimeout(()=>this.onRender(),hX>>2);
    this.options.onFrame?.({durationMs:performance.now()-e,flickers:[]});
    return
  }
}
// else: followScroll / selection / cell-diff write path continues...
```

Return-type handling summary (truthiness first, then string check):

1. `if (this.frameSink)` — absent → normal paint
2. `W = this.frameSink(c, this.stylePool)`
3. `if (W)` — `false` from alt-screen suspend → normal paint
4. swap frames + early return
5. `if (W === "tick")` — re-arm `drainTimer` at `hX>>2` (quarter frame interval; tip: `FRAME_INTERVAL_MS >> 2`)
